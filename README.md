# Tornado Chasing

A 3D storm chasing simulator built with **Unreal Engine 5**, combining C++ systems with Blueprint-based gameplay development.

## Current prototype

- Unreal Engine project and C++ module foundation.
- Blueprint-ready starter character.
- First-person / third-person camera toggle (V key).
- Initial roadmap for the playable prototype.

## Development

C++ will provide reusable gameplay foundations, while Blueprints will be used to prototype and extend gameplay in the Unreal Editor.

See [Docs/ROADMAP.md](Docs/ROADMAP.md) for planned milestones.

> This repository contains the source project structure. The Unreal Engine editor is required to generate project files, compile, and run the game.
